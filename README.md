# Thothica MLA constituency operations system

A proposal (August 2026) for a bilingual, WhatsApp-based system that helps Kerala MLAs run their
constituency offices. It is a concept with clickable demos on invented data, not a working product
yet.

- **Live page:** https://adoistic.github.io/thothica-mla-platform/
- **PDF deck:** [Thothica-MLA-constituency-operations.pdf](Thothica-MLA-constituency-operations.pdf)
- **Start here:** [HANDOFF.md](HANDOFF.md) explains what this is, what exists and what does not,
  in plain language.
