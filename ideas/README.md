# Ideas

One file per idea, named like `2026-11-20-short-name.md`. Plain language is fine. Adnan reads
these and replies or builds from them.

Copy this template:

```markdown
# <Idea in a few words>

From: Mr. Siraj
Date: <date>

## The idea
What should happen, in two or three sentences.

## Who it helps
The constituent, the MLA, or the office staff, and how.

## Where it fits
Rail A (civic issues and funds), Rail B (letters, invitations, appointments),
Rail C (messages from the office), or something new.

## An example
A real-life situation where this would matter.

## Anything to be careful about
Privacy, politics, cost, or anything else that comes to mind.
```
